# Daily

A calm, local-first planner for today. One-off tasks, routines, streaks, and a quiet history.

**Use it here: [https://danpaaku.github.io/daily-todo/](https://danpaaku.github.io/daily-todo/)**

No account. No login. No ads. Your lists stay on your device.

## What it does

- **Today** — Morning, Afternoon and Evening lists, plus a day score
- **Routines** — Daily, weekdays or weekly. Pause, resume, skip today, keep streaks
- **History** — Closed days and a 7-day consistency view
- **Settings** — Theme, default section, when your day starts, backup and reset

Unfinished one-off tasks carry into the next day. Routines do not pile up.

## Privacy

Anyone can open the link. They get an empty app, not your tasks.

Data lives in that browser on that device. Your phone and your computer are separate unless you export a backup on one and import it on the other.

## Install it like an app

Open the link above, then:

- **iPhone / iPad** — Safari → Share → Add to Home Screen
- **Android** — Chrome → menu → Install app
- **Windows / Mac** — Chrome or Edge → install icon in the address bar

## Backup

Settings → **Export backup** downloads a JSON file.  
**Import backup** replaces local data after a confirm summary. A broken file is rejected and nothing is overwritten.

Reset only clears Daily data in that browser.

## Limits

- No cloud sync
- Clearing site data deletes your lists
- Offline works after the first successful load
